Welcome to Nexflow

Nexflow is a decentralized AI inference aggregator designed to route developer prompts across frontier models with sub-second latency, powered by the $NF token economy.

The Core Philosophy

We believe builders shouldn't be locked into a single AI provider. With one unified API endpoint, your applications instantly gain multi-model redundancy across OpenAI, Anthropic, Gemini, Grok, and Llama.

Getting Started in 30 Seconds

Generate your API key from the dashboard, choose your model routing preference, and start shipping immediately.

API Reference

Nexflow uses a RESTful API standard that is fully compatible with the OpenAI SDK. If you can build with OpenAI, you can build with Nexflow.

Authentication

All requests must include your API key in the Authorization header.

Authorization: Bearer nx_live_YOUR_KEY_HERE

Chat Completions

To send a message, make a POST request to our chat endpoint:

POST https://api.nexflow.ai/v1/chat/completions

Nexflow will automatically route your request based on the model parameter provided. Use nexflow-auto to let us handle the best model selection for your specific task.
